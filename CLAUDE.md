# CLAUDE.md

Этот файл предоставляет руководство для Claude Code (claude.ai/code) при работе с кодом в этом репозитории.

## Обзор проекта

Приложение на базе PyQt5 для массового извлечения данных из умных электросчётчиков с использованием протокола DLMS/COSEM. Оно извлекает журналы счётчиков (напряжение, ток, мощность, самодиагностика, качество сети, журналы событий, профили и т.д.), записывает их в файлы Excel, выполняет автоматический анализ и отправляет результаты через Telegram.

## Архитектура

```

   │
   ├── libs/  — Логика приложения
   │   ├── connect.py            — Управление подключением (COM/TCP), переговоры скорости baud
   │   ├── read.py               — Опрос счётчика и извлечение логов (около 20+ листов Excel)
   │   ├── log_analysis_main.py  — Оркестровка анализа для каждого типа листа
   │   ├── log_analysis.py       — Правила валидации (корректность дат, хронологический порядок и т.д.)
   │   ├── Utils.py              — Вспомогательные функции (форматирование скаляров, разбор дат, создание листов Excel)
   │   ├── GXDLMSClient.py       --- УСТАРЕВШИЙ (перемещён) — смотрите gurux_lib/
   │   ├── config.py             — Датакласс конфигурации (COM, серийный номер, пароль, baud)
   │   ├── settings.py           — Централизованный конфигурационный файл (пароли, токены, таймеры, расписание)
   │   ├── check_time.py         — Отслеживание отклонения времени в пределах циклов опроса
   │   ├── check_self_diagnostic_log.py — Чтение журнала самодиагностики
   │   ├── sending_message.py    — Уведомления в Telegram (библиотека notifiers)
   │   ├── test_get_info_from_rsm.py — Клиент RSM API + тест pytest
   │   └── for_restart_driver.py — Автоматизация драйвера CH340 (win32gui)
   │
   ├── gurux_lib/ — Обёртки клиента DLMS/COSEM
   │   ├── GXDLMSClient.py       — Настройка подключения, аутентификация, разбор объектов
   │   ├── GXDLMSReader.py       — Основное чтение (методы read/write/list/profile)
   │   ├── GXDLMSSecureClient.py — Защищённый клиент (шифрование, GMAC/SHA256)

   │   └── __init__.py
   │
```

### Ключевой поток данных

1. **Подключение**: `connect.py` устанавливает соединение DLMS (COM или TCP), при необходимости ускоряет скорость baud (9600→115200 для RS, 9600→19200 для оптического порта)
2. **Извлечение**: `read.py` → `Utils.create_sheet_in_excel_file` читает около 20 типов логов в листы Excel через методы профилей `GXDLMSReader`
3. **Анализ**: `log_analysis_main.py` проверяет каждый лист (даты, порядок, дубликаты)
4. **Уведомление**: Результаты отправляются в Telegram через `sending_message.py`

### Плановые задачи (QTimer, опрос каждые 60 секунд)

- **11:03** — Опрос счётчика (`meter_survey` в `read.py`): чтение типа счётчика, серийного номера, отклонения времени, самодиагностики
- **11:10** — Выгрузка логов (`read_logs` в `read.py`): полное извлечение логов → Excel → анализ → Telegram

## Команды разработки

```bash
# Виртуальное окружение уже настроено
.venv\Scripts\activate

# Запуск GUI-приложения
python main_ui.py

# Установка/обновление зависимостей
pip install -r requirements.txt

# Запуск всех тестов
python -m pytest libs/test_get_info_from_rsm.py -v

# Запуск одного теста
python -m pytest libs/test_get_info_from_rsm.py::test_get_serial_number_from_stand -v

# Запуск тестов по маркеру (пользовательский маркер "asd" используется в test_get_info_from_rsm.py)
python -m pytest -m asd -v
```

## Тестирование

- Тесты находятся в `libs/test_get_info_from_rsm.py`
- Используется пользовательский маркер pytest `asd` (не зарегистрирован в pytest.ini — добавьте `-p no:cacheprovider` или зарегистрируйте в `pytest.ini`, если появляются предупреждения о неизвестных маркерах)
- Тесты требуют доступа к сети на `https://api.rsm.promenergo.local` (внутренний API RSM)

## Ключевые библиотеки

| Библиотека | Назначение |
|---------|---------|
| `PyQt5` | Фреймворк для GUI |
| `gurux_dlms` (в `libs/gurux/`) | Протокол DLMS/COSEM — вендорная, не обновлять через pip |

## Конфигурация

Все жёстко закодированные значения (пароли, токены, таймеры, расписание) теперь централизованы в файле `libs/settings.py`. Это позволяет легко изменять конфигурацию без правки основного кода.

| Параметр | Файл | Описание |
|---------|------|---------|
| `PASSWORD` | `libs/settings.py` | Пароль для подключения к счётчику |
| `AUTHENTICATION` | `libs/settings.py` | Тип аутентификации (`"High"`) |
| `CLIENT_ADDRESS` | `libs/settings.py` | Адрес клиента (`48`) |
| `TELEGRAM_BOT_TOKEN` | `libs/settings.py` | Токен Telegram-бота |
| `TELEGRAM_CHAT_ID_*` | `libs/settings.py` | ID чатов для уведомлений |
| `TIMER_INTERVAL_MS` | `libs/settings.py` | Интервал опроса таймеров (60000 мс) |
| `METER_SURVEY_START_TIME` | `libs/settings.py` | Время опроса счётчиков (`(11, 3)`) |
| `LOG_EXPORT_START_TIME` | `libs/settings.py` | Время выгрузки логов (`(11, 10)`) |
